# nixos/system

``hosts`` - конфигурационные ``.nix`` файлы, разделение которых на *хостовые* файлы *имеет смысл*. Учитывая, что в остальном используется скорее *ветвление*, чем меньше таких файлов, тем *чище*.
``modules`` - конфигурационные ``.nix`` файлы, применяющиеся глобально для текущих обслуживаемых хостов. Приветствуется использование ветвления (см. архитектуру ветвления).`
